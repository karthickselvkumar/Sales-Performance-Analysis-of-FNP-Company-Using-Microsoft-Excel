FNP Company Sales Data Analysis using Microsoft Excel
Project Overview

Analyzed FNP Company’s sales data using Microsoft Excel to uncover performance patterns and business insights.
This project focuses on identifying key trends, top-performing products, and seasonal variations to guide data-driven decisions.
🎯 Objectives

Understand overall sales performance and revenue trends.

Identify top-selling products and high-performing categories.

Detect seasonal fluctuations in sales across months or quarters.

Create an interactive dashboard for quick visualization and reporting.

🧰 Tools & Techniques
Category	Tools / Methods
Software	Microsoft Excel
Analysis Tools	Pivot Tables, Pivot Charts, Conditional Formatting
Functions Used	VLOOKUP, IF, SUMIFS, AVERAGEIFS, COUNTIFS
Visualization	Interactive Dashboards, Trend Lines, Bar and Pie Charts
Deliverables	Excel-based Dashboard & Sales Summary Report
⚙️ Project Workflow

Data Cleaning: Removed duplicates, handled missing values, and standardized columns.

Exploratory Analysis: Summarized data using Pivot Tables and formulas.

Trend Analysis: Identified monthly and quarterly sales patterns.

Performance Evaluation: Ranked products by total revenue and quantity sold.

Dashboard Creation: Designed an interactive Excel dashboard using charts and slicers for real-time filtering.

Insights Reporting: Compiled visual reports highlighting key findings.

📊 Key Insights

Certain product categories consistently outperformed others across seasons.

Sales showed strong seasonal peaks during festive and holiday months.

Top-performing regions contributed significantly to total company revenue.

Visual dashboards simplified management reporting and decision-making.

📈 Results & Impact

Improved understanding of sales dynamics and seasonal performance.

Helped identify top revenue-generating products and underperforming categories.

Supported strategic marketing and inventory planning through visual insights.

Enabled data-driven decisions across business teams.
